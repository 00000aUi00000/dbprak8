Task
-----------
Nennen Sie die 5 besten Produkte jedes Typs (Buch, Musik-CD, DVD) sortiert nach dem durchschnittlichem Rating. 

Hinweis: Geben Sie das Ergebnis in einer einzigen Relation mit den Attributen Typ, ProduktNr, Rating aus. 
         Wie werden gleiche durchschnittliche Ratings behandelt?



Query
-----------
SELECT * FROM (
    (SELECT 'Buch' as typ, produkt_id, rating 
        FROM produkt NATURAL JOIN buch 
        WHERE rating IS NOT NULL 
        ORDER BY rating DESC, (SELECT COUNT(*) FROM rezension WHERE rezension.produkt_id = produkt.produkt_id) DESC, produkt_id ASC
        LIMIT 5
    )
    UNION
    (SELECT 'Musik-CD' as typ, produkt_id, rating 
        FROM produkt NATURAL JOIN musikcd 
        WHERE rating IS NOT NULL 
        ORDER BY rating DESC, (SELECT COUNT(*) FROM rezension WHERE rezension.produkt_id = produkt.produkt_id) DESC, produkt_id ASC
        LIMIT 5
    )
    UNION
    (SELECT 'DVD' as typ, produkt_id, rating 
        FROM produkt NATURAL JOIN dvd 
        WHERE rating IS NOT NULL 
        ORDER BY rating DESC, (SELECT COUNT(*) FROM rezension WHERE rezension.produkt_id = produkt.produkt_id) DESC, produkt_id ASC
        LIMIT 5
    )
) as record
ORDER BY typ;


Notes
---------
Behandlung gleicher durchschnittlicher Ratings über absteigende Sortierung 
nach Anzahl an Rezensionen, dann alphabetische Sortierung nach ProduktID.
