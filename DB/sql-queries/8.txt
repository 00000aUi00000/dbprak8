Task
-----------
Geben Sie eine duplikatfreie und alphabetisch sortierte Liste der Namen aller Buchautoren an, die auch an DVDs oder Musik-CDs beteiligt sind.


Anmerkung:
Query liefert Datensätze mit ähnlichen Namen (B. B. King vs. B.B. King), VA und ähnliches
-----------
SELECT DISTINCT p.name
FROM autoren a
JOIN person p ON a.person_id = p.person_id
WHERE EXISTS (
    SELECT 1 FROM dvdrollen r WHERE r.person_id = a.person_id
)
   OR EXISTS (
    SELECT 1 FROM kuenstler k WHERE k.person_id = a.person_id
)
ORDER BY p.name;
