Task
-----------
Für welche Produkte ist das teuerste Angebot mehr als doppelt so teuer wie das preiswerteste?



Query
-----------
SELECT p.produkt_id
FROM produkt p
WHERE (
    SELECT MAX(ad.preis)
    FROM angebot a
    JOIN angebotsdetails ad ON ad.angebot_id = a.angebot_id
    WHERE a.produkt_id = p.produkt_id
      AND ad.preis IS NOT NULL
) > 2 * (
    SELECT MIN(ad.preis)
    FROM angebot a
    JOIN angebotsdetails ad ON ad.angebot_id = a.angebot_id
    WHERE a.produkt_id = p.produkt_id
      AND ad.preis IS NOT NULL
);
