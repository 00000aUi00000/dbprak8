Task
-----------
Welche Produkte haben sowohl mindestens eine sehr schlechte (Punktzahl: 1) als auch mindestens eine sehr gute (Punktzahl: 5) Bewertung?


Anmerkung: "Select 1" ist nur Platzhalter mit min. Overhead, hat keinen Einfluss auf Abfrage
Query
-----------
SELECT p.produkt_id
FROM produkt p
WHERE EXISTS (
    SELECT 1 
    FROM rezension r1 
    WHERE r1.produkt_id = p.produkt_id AND r1.punkte = 1
)
AND EXISTS (
    SELECT 1 
    FROM rezension r2 
    WHERE r2.produkt_id = p.produkt_id AND r2.punkte = 5
);
