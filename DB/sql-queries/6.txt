Task
-----------
Für wieviele Produkte gibt es gar keine Rezension?



Query
-----------
SELECT COUNT(*) AS produkte_ohne_rezension
FROM produkt p
WHERE NOT EXISTS (
    SELECT 1 
    FROM rezension r 
    WHERE r.produkt_id = p.produkt_id
);


Response
-----------
"produkte_ohne_rezension"
1219
(1 row)
